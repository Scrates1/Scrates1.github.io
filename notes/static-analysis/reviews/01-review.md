## 概念与论证

- 用同一分支程序贯穿状态、来源标记、抽象域、转移和合并；来源标记明确作为增广语义，不当作 Java 字符串自身属性。
- `γ(S)` 解释的是容许的具体状态。may 集合中的事实表示允许，不保证对应状态可达；空集合与不可达分别表示。
- 通过并集保留真实传播、错误交集遗漏真实传播，对比抽象精度损失和规则错误。
- 近似方向采用统一状态空间的包含关系 `U⊆R⊆O`。在例子中明确使用 `(flag,y来源)` 投影，目标性质只依赖该投影，不将变量名集合直接与具体状态集比较。
- 按与 Bad 的交集区分“证明安全”和“证明存在错误”的条件。没有把任意缺少告警、限时探索或符号路径当作严格保证。
- soundness 在正文限定为本系列的过近似覆盖要求；欠近似另有可达性保证，没有称其为不可靠的分析。
- 保留 may/must 与近似方向的区别：保证事实减少，可以对应更多具体状态。

依据核对：[Static Program Analysis](https://cs.au.dk/~amoeller/spa/spa.pdf)、[抽象解释原论文介绍](https://www.di.ens.fr/~cousot/COUSOTpapers/POPL77.shtml)、[Incorrectness Logic 作者论文](https://www0.cs.ucl.ac.uk/staff/p.ohearn/papers/IncorrectnessLogic.pdf)。后者搜索取得的正文片段涵盖欠近似规则及反例，本轮完整 PDF 直连返回 502；未声称重新通读全文。
