想要一个用起来更方便的 Vim，可以选 [Neovim](https://neovim.io/) 搭配 [LazyVim](https://www.lazyvim.org/)。Neovim 沿用 Vim 的模式和按键，LazyVim 则是一套现成的配置：查找文件、全文搜索、代码补全和按键提示都已配好，不必从零写配置。

这篇文章面向已经能在终端启动 `nvim` 的初学者。分清模式，再掌握少量可以组合的编辑命令，就能完成日常编辑；你可以跟着练习完成第一次编辑，也可以在日常使用时查找快捷键。

使用速查表时注意：

- `gg`、`ciw`、`空格 → f → f` 都是**依次按**；`Ctrl+r` 是**同时按**。
- 大小写有区别。`G` 通常用 `Shift+g` 输入。
- 表中的 `/` 有时用于分隔可选按键，例如 `h / j / k / l`，每次选一个按。
- 冒号命令及 `/关键词`、`?关键词` 都要按回车确认。其他普通模式组合通常直接执行。
- 英文列提供助记词或动作名称；约定键位不一定对应英文首字母。详细读法见[看懂按键记法](#_3-看懂按键记法)。

“原生”表示 Neovim 自带；“LazyVim”表示本文环境沿用的官方默认映射。作者为全局安装新增的维护设置另列在附录。

### 输入

| 按键或命令 | 作用 | 英文助记 | 模式与来源 |
| --- | --- | --- | --- |
| `i` | 在光标前输入 | Insert | 普通 → 插入；原生 |
| `a` | 在光标后输入 | Append | 普通 → 插入；原生 |
| `I` | 从行内首个非空白字符前输入 | Insert | 普通 → 插入；原生 |
| `A` | 在行尾输入 | Append | 普通 → 插入；原生 |
| `o / O` | 在下面／上面新建一行并输入 | Open a new line | 普通 → 插入；原生 |
| `Esc` | 结束输入或取消选择、命令输入 | Escape | 插入、可视、命令行等；原生 |
| `Ctrl+[` | 结束插入或替换的另一种按法 | Escape 等效操作 | 插入、替换；原生 |

LazyVim 给 `Esc` 增加了清除搜索高亮、停止代码片段等行为。内置终端的退出方法见[内置终端](#内置终端)。

### 移动

| 按键或命令 | 作用 | 英文助记 | 模式与来源 |
| --- | --- | --- | --- |
| `h / j / k / l` | 左／下／上／右移动 | Left / Down / Up / Right | 普通、可视；原生 |
| `w` | 向前到下一单词开头 | Word | 普通、可视；原生 |
| `b` | 向后到单词开头 | Back | 普通、可视；原生 |
| `e` | 到单词末尾 | End of word | 普通、可视；原生 |
| `0` | 到行的最开头 | 约定键位 | 普通、可视；原生 |
| `^` | 到行内首个非空白字符 | 约定键位 | 普通、可视；原生 |
| `$` | 到行尾 | End of line | 普通、可视；原生 |
| `gg / G` | 到文件开头／末尾 | Go to first / last line | 普通；原生 |
| `20G` | 到第 20 行，数字可替换 | Go to line | 普通；原生 |
| `5j / 3w` | 下移五行／前移三个单词 | Count + motion | 普通；原生 |
| `Ctrl+d / Ctrl+u` | 向下／向上滚动半屏 | Down / Up | 普通；原生 |
| `fa` | 找当前行后面的下一个字母 a | Find | 普通；原生 |
| `%` | 在配对括号之间跳转 | Match，约定键位 | 普通；原生 |
| `Alt+j / Alt+k` | 向下／向上移动当前行或所选多行 | Move down / up | 普通、插入、可视；LazyVim |

LazyVim 对 `j/k` 有显示行增强：单按时照顾屏幕折行，带数字时按实际文件行移动。`w/b/e` 按编辑器的单词边界工作；中文连续文本的跳转不等同中文分词。

### 修改与复制

| 按键或命令 | 作用 | 英文助记 | 模式与来源 |
| --- | --- | --- | --- |
| `d / y / c` | 开始删除／复制／修改，等待范围 | Delete / Yank / Change | 普通 → 等待范围；原生 |
| `dd / yy` | 剪切／复制当前整行 | Delete / Yank | 普通；原生 |
| `cc` | 修改当前整行，保留缩进并输入 | Change | 普通 → 插入；原生 |
| `dw / d$` | 从光标删到下一词开头／行尾 | Delete + motion | 普通；原生 |
| `y$` | 从光标复制到行尾 | Yank + motion | 普通；原生 |
| `diw` | 删除整个当前单词 | Delete inner word | 普通；原生 |
| `ciw` | 替换整个当前单词并开始输入 | Change inner word | 普通 → 插入；原生 |
| `yiw` | 复制整个当前单词 | Yank inner word | 普通；原生 |
| `ci"` | 替换双引号里面的内容 | Change inside quotes | 普通 → 插入；原生 |
| `3dd` | 从当前行开始剪切三行 | Count + Delete | 普通；原生 |
| `x` | 删除光标下一个字符 | Delete character，约定键位 | 普通；原生 |
| `rX` | 把光标下一个字符换成 X | Replace | 普通；原生 |
| `R` | 连续覆盖输入，直到按 Esc | Replace mode | 普通 → 替换；原生 |
| `p / P` | 在后面／前面粘贴 | Put | 普通；原生 |
| `u / Ctrl+r` | 撤销／重做编辑 | Undo / Redo | 普通；原生 |
| `.` | 在新位置重复上一次修改 | Repeat last change | 普通；原生 |

`rX` 中的 `X` 是示例替换字符。粘贴整行时，`p/P` 分别放到当前行下面／上面；字符内容则放到光标后面／前面。删除也会更新寄存器，后续 `p` 可能粘贴最近删除的内容。组合原理见[操作符与文本对象](#操作符与文本对象)。

| --- | --- | --- | --- |

| `V` | 按整行选择 | Visual line | 普通 → 可视；原生 |

### 保存与退出

以下冒号命令从普通模式开始输入，最后按回车。

| 按键或命令 | 作用 | 英文助记 | 模式与来源 |
| --- | --- | --- | --- |
| `:w` | 保存当前文件 | Write | 命令行；原生 |
| `:w notes.md` | 首次给空白 Buffer 命名并保存 | Write | 命令行；原生 |
| `:saveas other.md` | 另存新文件并切换当前文件名，旧文件保留 | Save as | 命令行；原生 |
| `:q` | 关闭当前窗口，未保存时可能提示 | Quit | 命令行；原生 |
| `:wq` | 保存当前文件并关闭当前窗口 | Write + Quit | 命令行；原生 |
| `:q!` | 不写入磁盘，强制关闭当前窗口 | Quit without writing | 命令行；原生 |
| `:wa` | 保存全部可写且已命名的修改 Buffer | Write all | 命令行；原生 |
| `:wqa` | 全部保存成功后退出所有窗口 | Write + Quit all | 命令行；原生 |
| `Ctrl+s` | 保存并返回普通模式 | Save | 普通、插入、可视；LazyVim |
| `:pwd` | 查看当前工作目录 | Print working directory | 命令行；原生 |
| `:cd ~/nvim-practice` | 切换到练习目录 | Change directory | 命令行；原生 |

> **记住**：`:q!` 首先是关闭窗口的命令。同一 Buffer 仍在另一窗口显示时，未保存内容可以继续保留。它也不会回退已经写入磁盘的内容。

具体例子见[同一缓冲区的多个窗口](#_7-同一缓冲区的多个窗口)。

未命名 Buffer 可以用 `:w notes.md` 第一次命名；已命名 Buffer 执行 `:w other.md` 是向另一个文件写入内容，切换当前文件名使用 `:saveas`。保存失败时先处理提示，确认后再退出。

### 搜索与替换

| 按键或命令 | 作用 | 英文助记 | 模式与来源 |
| --- | --- | --- | --- |
| `/关键词`，回车 | 向文件后面搜索 | Search forward | 普通 → 命令行；原生 |
| `?关键词`，回车 | 向文件前面搜索 | Search backward | 普通 → 命令行；原生 |
| `n / N` | 跳到后一个／前一个匹配 | Next / Previous | 普通；LazyVim 的方向约定 |
| `Esc` | 清除搜索高亮 | Clear search highlight | 普通；LazyVim |
| `:%s/old/new/gc` | 全文件逐项确认替换 | Substitute | 命令行；原生 |
| `y / n / q` | 确认替换／跳过／结束替换 | Yes / No / Quit | 替换确认中；原生 |

在原生 Neovim 中，`n/N` 方向跟随上一次搜索方向；本文 LazyVim 环境把 `n` 固定为向后面的匹配移动，`N` 为向前面的匹配移动。搜索词使用正则表达式，初学先用普通文字。

替换命令中：`%` 表示当前文件全部行，`s` 是 Substitute，`g` 表示每行的所有匹配，`c` 表示 Confirm、逐项确认。其范围是当前文件。

## 从头学习

这一部分使用原生命令完成一次编辑流程。熟悉后，再用速查表里的 LazyVim 组合键加快操作。

练习路线：

1. [创建练习目录](#_1-准备练习目录)，分清模式与按键记法。
2. [输入并保存](#_4-输入并保存第一份文件)，练习移动、修改、复制与搜索。
3. [观察分屏同步](#_7-同一缓冲区的多个窗口)，打开第二份文件。
4. [检查最终结果](#_9-保存并验证结果)。

### 1. 准备练习目录

先在终端创建独立的练习目录。以下 shell 示例适用于 Linux／macOS；在 Paseo 中选择 **Terminal／终端**后输入：

```bash
mkdir -p ~/nvim-practice
cd ~/nvim-practice
nvim practice.md
```

下面假定 `practice.md` 是一个空白的新文件。如果已经存在练习内容，换一个未使用的文件名，再跟随操作。

**预期结果：** 打开一个空白编辑区域，显示新文件名称，通常处于 Normal 模式。准备新 Buffer 后，执行保存才会创建磁盘文件。

### 2. 分清模式与工作区

Neovim 是模态编辑器（Modal editor）。同一个文件里，按键会根据模式解释成输入文字或执行命令。

| 模式 | 作用 | 进入与退出 |
| --- | --- | --- |
| Normal：普通模式 | 移动、复制、删除和使用组合键 | 编辑启动后通常处于此模式 |
| Insert：插入模式 | 输入文字 | 普通模式按 `i` 等进入，`Esc` 返回 |
| Visual：可视模式 | 先选中文字，再操作 | `v`、`V` 或 `Ctrl+v` 进入，`Esc` 取消 |
| Command-line：命令行模式 | 输入保存、搜索等命令 | 普通模式按 `:`、`/`、`?`，回车执行或 `Esc` 取消 |

```text
Normal → i → Insert → 输入文字 → Esc → Normal
Normal → v → Visual → 选择文字 → y 复制 → Normal
Normal → : → 输入命令 → 回车执行
```

其他概念各管一件事：

| 概念 | 英文 | 含义 |
| --- | --- | --- |
| 编辑模式 | Mode | 当前按键如何解释 |
| 缓冲区 | Buffer | 文件在内存里的编辑内容；也可以是帮助、终端等特殊内容 |
| 窗口 | Window | 显示一个 Buffer 的区域，可以分屏 |
| 标签页 | Tabpage | 一组窗口布局 |
| 工作目录 | Working directory／cwd | 相对文件路径的起点，用 `:pwd` 查看 |
| 项目根目录 | Project root | 根据 Git、语言服务等识别的项目范围 |
| Paseo 工作区 | Workspace | Paseo 中组织项目、聊天、终端的环境 |

切换模式不会创建工作区或文件。Paseo 把终端画面和按键连接到运行 Neovim 的主机；编辑和保存的也是那台主机上的文件。

### 3. 看懂按键记法

把文档写法翻译成真实动作即可，功能还要结合模式判断。

| 文档写法 | 实际按法 |
| --- | --- |
| `gg` | 按一下 g，松开，再按一下 g |
| `G` | 输入大写 G，通常是 Shift+g |
| `Ctrl+r`／`<C-r>` | 按住 Ctrl，按一下 r，再松开 |
| `<S-h>` | Shift+h，即大写 H |
| `<A-j>` | Alt+j |
| `<Esc>` | 按 Escape 键 |
| `<CR>` | Carriage Return，按一次回车 |
| `<leader>` | 前缀键，LazyVim 默认是空格 |
| `<leader>ff` | 依次按空格、f、f |
| `:w<CR>` | 输入英文冒号和 w，再按回车 |

> **容易混淆**：`<CR>` 是回车，`<C-r>` 是 Ctrl+r。

箭头、尖括号中的名称属于说明记号，操作时转换为对应按键。

在 Paseo 中先点终端，让它获得键盘焦点。执行字母命令时使用英文输入法；输入中文正文时再切回中文。

### 4. 输入并保存第一份文件

按 `i`，输入三行文字：

```markdown
# Neovim 学习记录
apple banana cherry
今天练习输入、修改和保存。
```

然后按 `Esc`，输入 `:w`，按回车。

**预期结果：** 文字保留在编辑区域，回到普通模式，出现写入成功的提示；文件保存在练习目录中。可用 `:pwd` 查看目录。

编辑流程可以理解为：

```text
磁盘文件 → 加载到 Buffer → 修改内存中的文字 → 保存到磁盘
```

未命名 Buffer 第一次保存时可执行 `:w notes.md`。文件后缀按内容选择：`.md` 适合笔记与文档，`.txt` 是纯文本，`.py` 是 Python 代码，`.lua` 是 Lua 代码。文件类型与编辑模式是不同维度。

LazyVim 默认开启 `autowrite`，部分操作会触发写入。养成在明确阶段执行 `:w` 的习惯；`:q!` 不会回退已经保存的内容。

### 5. 移动与修改文字

先按 `gg` 到第一行，再按 `j` 到第二行，按 `0` 到这一行开头。

此时可以用 `w`、`b`、`e` 观察单词移动。正式修改前，再用 `gg`、`j`、`0` 回到 `apple` 开头。

依次按 `c`、`i`、`w`，输入 `orange`，再按 `Esc`。

**预期结果：** 第二行变为：

```text
orange banana cherry
```

`ciw` 是 Change inner word：选择整个当前单词，删除后进入插入模式。按 `u`，它恢复为 `apple`；在普通模式按 `Ctrl+r`，又恢复为 `orange`。若客户端未传递 Ctrl+r，可用原生命令 `:redo` 完成这一步。

模式改变的是按键含义：普通模式的 `i` 会进入插入，插入模式的 `i` 会写出字母。状态栏能帮助判断当前模式。

### 6. 选择复制与搜索

继续在第二行练习：

1. 按 `yy`，再按 `p`：复制整行并在下面粘贴，暂时多出一行。
2. 按 `u`：撤销这次粘贴，恢复为三行。
3. 按 `gg`、`j` 回第二行，按 `V`，再按 `j`：选中第二、三行。
4. 按 `y` 复制，按 `G` 到末尾，再按 `p`：把这两行复制到文件末尾。
5. 按 `u`：再次撤销粘贴，文件恢复三行。

复制、剪切使用寄存器（Register）暂存内容，`p` 取出内容。内部寄存器与手机或电脑的系统剪贴板是两层机制，跨应用操作见附录。

现在输入 `/a` 并回车，用 `n`、`N` 在第二行多个 a 之间移动。搜索只有一个匹配时，继续查找可能绕回同一位置。

接着执行：

```vim
:%s/banana/grape/gc
```

确认时按 `y`。

**预期结果：** 第二行变为 `orange grape cherry`。输入 `:w` 保存。

替换命令的 `%` 表示全部行，`s` 是 Substitute，`g` 表示每行所有匹配，`c` 是 Confirm、逐项确认。搜索输入是正则表达式，初学先用普通文字。

### 7. 同一缓冲区的多个窗口

先按 `gg`，再执行：

```vim
:vsplit
```

**预期结果：** 出现左右两个窗口，都显示同一个练习文件。新窗口的位置由配置决定。

在当前窗口按 `gg`、`A`，追加 `（同步测试）`，再按 `Esc`。另一窗口也会显示这次修改，即使尚未保存。

原因是：多个窗口是同一份 Buffer 内容的多个视图。

| 项目 | 是否共享 |
| --- | --- |
| 编辑中的文字、未保存状态 | 共享 |
| 撤销与重做历史 | 共享 |
| 光标与滚动位置 | 默认各自保留；增删行时位置可能随文本调整 |

在 LazyVim 中用 `Ctrl+h`、`Ctrl+l` 切换窗口。原生 Neovim 可以先按 `Ctrl+w`，再按 `h` 或 `l`。两个窗口分别执行 `:echo bufnr()`，相同编号表示显示同一个 Buffer。

此时执行一次 `:q!`：只关闭当前窗口，剩下的窗口仍保留追加后的标题和未保存状态。再执行 `:w` 保存。

这解释了为什么“关闭窗口”和“丢弃 Buffer 修改”需要分开理解。只有一个窗口、没有其他待处理 Buffer 的常见入门场景中，`:q!` 才会退出编辑器并放弃未保存改动。

分别在两个 Paseo 终端启动 Neovim，属于两个独立实例，通常各自维护 Buffer；另一个实例需通过磁盘保存、重载等方式看到变化。

### 8. 打开另一个文件

在剩下的窗口中执行：

```vim
:vsplit todo.md
```

新窗口准备了另一份文件 Buffer。按 `i`，输入 `今天完成第一次 Neovim 练习。`，按 `Esc`，执行 `:w`。

**预期结果：** 两个窗口显示不同文件；修改 `todo.md` 不会改变 `practice.md`。

用 `:ls` 查看 Buffer 列表，也可以用 LazyVim 的 `空格 → ,` 选择文件。`空格 → b → d` 关闭 Buffer，`空格 → w → d` 关闭窗口；磁盘文件保留。

Neovim 上方一排文件名在 LazyVim 中通常是 Buffer 列表。真正的 Tabpage 管理整组窗口布局，可用 `:tabnew` 新建，`gt/gT` 切换。

### 9. 保存并验证结果

执行 `:wqa`，保存并退出所有窗口。无法保存时会提示原因，处理后再退出。

回到外层终端检查：

```bash
cat practice.md
cat todo.md
```

如果完整执行了上述必做步骤，`practice.md` 应为：

```markdown
# Neovim 学习记录（同步测试）
orange grape cherry
今天练习输入、修改和保存。
```

`todo.md` 应只有这一行：

```text
今天完成第一次 Neovim 练习。
```

再运行 `nvim practice.md`，可以继续编辑。若结果不同，先检查是否执行了练习中的撤销操作、确认替换，以及最终保存。

## 进阶理解

### 操作符与文本对象

Neovim 命令可以组合，基本形式是：

```text
次数 + 操作符 + 移动范围或文本对象
```

`d` 是 Delete，`y` 是 Yank，`c` 是 Change。按下操作符后，编辑器等待范围，这叫 **Operator-pending**。

- `dw`：从光标删除到下一单词开头。
- `d$`：删除到行尾。
- `y$`：复制到行尾。
- `dd/yy/cc`：重复操作符，作用于整行。
- `3dd`：从当前行开始删除三行。

文本对象（Text object）描述完整单元：`iw` 是 Inner word，`aw` 是 A word、通常连同相邻空白；`i"` 表示双引号内部。

例如，在 `message = "hello world"` 的引号内容中按 `ci"`，输入新内容再按 `Esc`，两侧引号保留。在另一个位置按 `.`，可以重复上一次修改。

这里的 `i` 表示 Inner／Inside，和单独按 `i` 进入 Insert 的上下文不同。重复操作符的整行规则适用于 `dd/yy` 等组合，不能套用到所有重复字母上。

### 替换模式与选择模式

`rX` 是一次替换，完成后仍在 Normal；`R` 会进入 **Replace**，连续覆盖输入，直到按 `Esc`。

**Select** 模式允许输入文字直接替换选中内容，部分代码片段占位符会使用它。初学先掌握 Normal、Insert、Visual、Command-line 四种模式，再认识这些附加状态。

### 代码能力的三个组成

语法高亮、语言服务、格式化是不同能力：

| 能力 | 作用 | 常见实现 |
| --- | --- | --- |
| 语法解析与高亮 | 识别代码结构、提供高亮等 | Treesitter 及语言解析器 |
| 语言服务 | 理解符号，提供跳转、引用、重命名、诊断等 | Language Server Protocol，LSP |
| 格式化 | 按规则重新排版 | 对应格式化程序 |

因此，有 Python 高亮不等于已经具备 Python 语言服务；按 `空格 → c → f` 也需要当前语言有可用格式化工具。`Ctrl+o` 返回跳转历史则是原生功能，不依赖 LSP。

作者环境已验证 Lua 服务初始化和 Lua 格式化。可以用一个 `example.lua` 文件，逐步练习跳转、返回和格式化；具体交互的验证范围见附录。

### 在编辑器里运行终端

外层终端负责启动 `nvim`；在 Neovim 中执行 `:terminal`，会再打开一个终端 Buffer。进入 **Terminal** 输入模式后，按键交给其中的程序。

返回 Neovim 普通模式：先按 `Ctrl+\`，再按 `Ctrl+n`。随后可以移动和选择输出，按 `i` 继续向 shell 输入。

这里的退出方式和 Insert 不同。LazyVim 的 `空格 → f → t` 是项目根目录终端入口。

## 常见问题

| 现象 | 优先检查与处理 |
| --- | --- |
| `i`、`dd` 或 `:w` 出现在正文中 | 当前可能在 Insert；按 `Esc`，再使用普通模式命令 |
| 无法直接输入文字 | 看状态栏，可能在 Normal；按 `i` 开始输入 |
| 看见 `<CR>`，不知道按哪个键 | 它是回车；`<C-r>` 才是 Ctrl+r |
| 保存到了意料之外的位置 | 执行 `:pwd`，必要时使用绝对路径 |
| `ff` 和目录中的文件范围不同 | 区分项目根目录与 cwd，比较 `ff/fF` |
| `p` 粘贴了刚删除的内容 | 默认寄存器可能被删除操作更新 |
| 关闭一个分屏后文字修改还在 | 另一窗口仍显示同一 Buffer；关闭窗口和还原内容是两件事 |
| `:q!` 没有回到以前的磁盘内容 | 它不回退已保存版本；已经保存的修改可通过撤销后再保存来调整 |
| 终端中按 Esc 没回到普通模式 | 使用 `Ctrl+\`，然后 `Ctrl+n` |
| 某语言没有跳转或格式化 | 核实该语言的服务、格式化工具及功能支持 |
| 组合键触发了客户端操作 | 确认终端焦点和客户端对特殊键的传递方式 |
