这个系列从一段 Java 污点程序出发，介绍程序表示、数据流规则、过程间求解，以及精度与计算成本。面向熟悉 Java、第一次接触静态分析的开发者，按一门课的方式顺读。

第 02、04 篇与第 11 篇配有可运行的 Soot 示例，其余篇目通过计算推演和原始文献讲解。

## 怎样读这门课

- 每篇开头有“读前须知”，说明需要先读哪几篇；结尾有要点或总结，读完先合上页面自己复述一遍，再对照。
- 遇到公式先看紧跟其后的直白说法，再回头看公式；每个符号首次出现时都给了读法。所有术语集中在[术语表](99-glossary.md)，忘了就查。
- 每篇的表格推演（逐点事实表、工作列表表、摘要步骤表）都可以手算：先盖住结果列，自己算一遍，再对照。这比读三遍更有效。
- 第 02、04 篇和第 11 篇有可运行示例，建议实际跑一次，把输出和正文的表对上。
- 09、10 是专题，第一遍可以跳过；05 是值分析基础，只关心污点分析的读者可以先跳过，到 08 之前再补。

## 阅读路线

- **首次系统阅读**：01—08 顺读，再读 11，最后选读 09、10。
- **先建立整体认识**：01→02→03→04。
- **以污点理解 IFDS**：01→02→03→04→06→07。
- **深入值计算**：补上 05，再进入 08→10。
- **关心路径精度**：06→09；09 的 IFDS/IDE 比较部分在 07、08 后阅读。
- **走向真实 Java 污点分析**：06→11（07 可选，只在说明事实域为何看不到字段时用到），再接后续的污点分析实践与覆盖边界两篇。

依赖图中的实线表示前置知识，虚线表示比较部分的额外前提。09、10、11 是独立专题，05 也不是学习过程间污点传播的必修前提。
