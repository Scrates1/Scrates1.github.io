搜索引擎：如果你经常搜索的是技术方面问题，推荐使用Google或者Bing。

<!-- more -->

* 使用**关键词**，而非句子，因为长句子中的无用的词语，会降低搜索引擎得到有用的信息的概率
  比如，使用

  ```
  python turn list item to indexed tuple
  ```

  而非

  ```
  how do I turn a list item to an indexed tuple in Python?
  ```

  例外：对于错误信息，把有用的直接复制粘贴就可以（无用的比如代码第几行报错、文件名等，就不用复制）

* 保证自己的关键词比较**通用**(也就是遇到问题大家都会用的一些词语)

* 这个关键词不行，换个近义词试试

* 平时注意积累本领域常用的中文词汇对应的英语词汇

* 递进式检索–从搜索结果中寻找蛛丝马迹：

  例如，我们看到别人在视频中使用 Vim 的命令行模式时，可以使用 Tab 来补全命令的参数或者补全命令，这个需要进行设置才能生效或者达到自己需要的效果，但是我们不知道应该设置哪个选项，可以使用初步的检索词

  ```fallback
  vim Tab Completion Command line
  ```

  然后从[返回结果](https://www.google.com/search?q=vim+Tab+Completion+Command+line)找到[这个页面](https://vi.stackexchange.com/q/11411/15292)，进而知道有两个选项控制 vim 在命令行的自动补全功能，分别是 wildmenu 和 wildmode，知道这个以后，就可以比较轻松的找到相关的设置了。
